# Babble textured emojis

Animated emoji collection prepared by Krimsonhouse.

This delivery contains **2,039 approved animations across 684 designs**.

## Files

`assets/` preserves the original design folders, skin-tone folders and animation
filenames. The animations are native 256 × 256 APNG files. Each design includes
its original metadata.

`manifest.json` records the delivered files and SHA-256 hashes.
`checksums.sha256` covers the animations and metadata.

## Download

Install Git and Git LFS, then run:

```sh
git lfs install
git clone https://github.com/Krimsonhouse/Babble-textured-emojis.git
cd Babble-textured-emojis
git lfs pull
git lfs fsck
```

Use Git LFS to download the full animation files.
